# Cycle Tracker

Mini web-app mobile pour suivre le cycle A/B/C sur 4 semaines.

## Publication GitHub Pages — environ 2 minutes

1. Sur GitHub, crée un nouveau repository, par exemple `cycle-tracker`.
2. Mets-le en **Public**.
3. Décompresse cette archive.
4. Envoie les **3 fichiers** (`index.html`, `manifest.webmanifest`, `service-worker.js`) à la racine du repository.
5. Dans GitHub : **Settings → Pages**.
6. Dans **Build and deployment**, choisis **Deploy from a branch**.
7. Branche : `main`, dossier : `/ (root)`, puis **Save**.
8. GitHub donne ensuite l'adresse de ton appli, du type :
   `https://TON-PSEUDO.github.io/cycle-tracker/`

Sur iPhone : ouvre cette adresse dans Safari → Partager → **Sur l'écran d'accueil**.
Sur Android : ouvre l'adresse dans Chrome → menu → **Ajouter à l'écran d'accueil**.

Les données d'entraînement sont stockées localement dans le navigateur de l'appareil.
