UTILISATION LOCALE
Ouvre index.html dans un navigateur. Les séances et bilans sont sauvegardés localement sur cet appareil et dans ce navigateur.

PUBLICATION GITHUB PAGES
1. Décompresse le dossier hybrid-athlete-juin-2027.
2. Dépose les 4 fichiers du dossier à la racine du dépôt GitHub (ou dans le dossier publié).
3. Dans Settings > Pages, choisis la branche et le dossier contenant index.html.
4. Ouvre l’URL GitHub Pages sur l’iPhone puis utilise Partager > Sur l’écran d’accueil.

DONNÉES
Utilise « Exporter sauvegarde » régulièrement pour conserver une copie JSON de tes séances et bilans. La version 4 migre automatiquement les données locales de la version 3 sans supprimer l’ancienne clé. Une publication sur une nouvelle origine/domaine ne transfère pas automatiquement le stockage local du navigateur.

PROGRESSION
Le coach intégré est un moteur de règles transparent fondé sur les reps, le RIR, la douleur et la tolérance à J+1. Ce n’est pas un modèle d’IA générative. Une progression de charge n’est débloquée qu’après validation de la tolérance à J+1.
